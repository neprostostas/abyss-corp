# Profile avatar artwork

Generated with the built-in imagegen tool, one image per avatar. Production assets are 256 × 256 WebP files in `public/avatars/`, resized from the original generated PNGs. No external API or keys were used.

## Prompt template

Create ONE square avatar illustration for Abyss Corp, an underwater idle game. Subject: {subject}. Style: polished hand-drawn game icon, simple geometric silhouette, dark navy outlines, subtle flat shaded facets, soft cyan underwater glow, warm pale gold accents. Background solid deep teal #173e4b. Centered subject fills 75% of square, generous safe circular crop margins. No text, no letters, no border, no UI, no multiple panels. Production game profile avatar, readable at 44px.
