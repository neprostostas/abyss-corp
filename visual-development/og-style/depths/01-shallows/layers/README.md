# Crystal shallows — пробні шари

П'ять PNG — окремі варіанти, створені вбудованим ImageGen з відповідних
`*-concept.png`. Промпт для кожного: «preserve the original subject, design,
colors, lighting and three-quarter viewpoint; remove background glow and scenery;
transparent background, clean edges and generous margins; do not redesign».
Оригінальні концепти залишено поруч без змін.

`../layer-study.html` — локальна пробна збірка саме з цих п'яти PNG у вигляді
окремих HTML-шарів. Перемикачі водного, світлого, білого й темного тла допомагають
оглянути контури. Позиції та масштаби підібрані вручну лише для оцінки.

Результат: усі п'ять мають RGBA і прозорі кути. Бур, склад і субмарина виглядають
ізольованими; у платформи й refinery автоматичне редагування залишило значне
навколишнє свічення, попри запит на його видалення. Краї та дрібні артефакти
потребують подальшої ручної перевірки. Автоматичне редагування може змінити дрібні
деталі й не створює окремих компонентів для анімації.

Композиція краще показує загальні пропорції, але не доводить готовність активів:
перспектива об'єктів і посадка на платформу умовні, бур містить додаткову будівлю,
окремих шарів для руху немає. Макет показує не реальний ігровий viewport або HUD.
Перевірено завантаження п'яти зображень і перемикачів тла в Chrome/WebKit на
390×844 та 1200×900; візуально переглянуто водне й біле тло. Код гри не змінено.
